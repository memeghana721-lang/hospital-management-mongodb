# 🏥 Hospital Management System (MongoDB)

A full-stack **Hospital Management System** developed using **Spring Boot**, **React.js**, and **MongoDB**. This application helps hospitals efficiently manage doctors, patients, appointments, beds, and billing through a modern and user-friendly web interface.

---

## 📌 Project Overview

The Hospital Management System is designed to simplify day-to-day hospital operations by providing separate modules for managing hospital resources and patient services. The backend exposes RESTful APIs using Spring Boot, while the frontend is developed with React.js for a responsive user experience.

---

## ✨ Features

### 👨‍⚕️ Doctor Management
- Add New Doctor

- Update Doctor Information
- Delete Doctor Records

### 🧑 Patient Management
- Register New Patient
- View Patient Details

- Delete Patient Records

### 📅 Appointment Management
- Book Appointment
- View Appointment Details
- Update Appointment
- Cancel Appointment

### 🛏️ Bed Management
- Add Hospital Beds
- Assign Beds to Patients
- Update Bed Availability
- View Bed Status

### 💳 Billing Management
- Generate Bills
- Update Billing Information
- View Billing Records
- Delete Billing Records

# ⚙️ Installation & Setup

## Backend

Clone the repository

```bash
git clone https://github.com/memeghana721-lang/hospital-management-mongodb.git
```

Navigate to backend

```bash
cd Hospital-Backend
```

Run the Spring Boot application

```bash
mvn spring-boot:run
```

---

## Frontend

Navigate to frontend

```bash
cd Hospital-Frontend
```

Install dependencies

```bash
npm install
```

Start the React application

```bash
npm start
```
